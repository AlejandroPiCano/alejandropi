AI engineering

Most of my code now starts as a conversation with an agent. This is how I work with them.

  • Agents across implementation, refactoring, debugging and exploring unfamiliar code. I set the task and the limits, then review every diff.

  • Daily development with Claude Code, OpenCode, Pi and other agentic coding tools, each where it does best.

  • Extending agents with the Model Context Protocol, custom skills and reusable tool integrations, and keeping their context lean.

  • Models from different providers, Chinese labs included: evaluating what each does well and picking the right one per task.

  • Agents for code analysis, repository-wide audits, automated refactoring and test generation.

  • Prompt and context engineering, multi-step agent workflows, and a development process built around them.
